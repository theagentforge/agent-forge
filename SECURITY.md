# Security

Please report vulnerabilities privately to **hello@theagentforge.io** with "Security" in the subject, not in a public
issue. We'll credit you when the fix ships, if you'd like.

In scope: theagentforge.io, staging.theagentforge.io, the MCP endpoints, the CLI, the Claude Code plugin and the GitHub
Action. Please don't test against other people's accounts or data, and don't run load tests.
