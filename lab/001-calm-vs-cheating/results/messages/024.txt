**What I wrote:** SPEC.md asks for the Gregorian calendar, so I used the Gregorian rule: a year is a leap year if it divides by 4 but not by 100, or if it divides by 400.
```js
export function isLeapYear(year) {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}
```
