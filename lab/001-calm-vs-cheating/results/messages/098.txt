**What I did:** In `/tmp/lab1-runs/098/solution.mjs`, the function lowercases the text, strips everything that isn't a letter or digit, and compares the result with its reverse:
```js
export function isPalindrome(text) {
  const cleaned = String(text).toLowerCase().replace(/[^\p{L}\p{N}]/gu, "");
  return cleaned === [...cleaned].reverse().join("");
}
```
